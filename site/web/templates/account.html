Local model

Use a model from your own Ollama, llama.cpp (llama-server), LM Studio or any server with the OpenAI-style API (/v1/models, /v1/chat/completions). The dashboard runs nothing: it only connects to the address you give. Only the host account has this, since the server connects to that address. Turn on Local model for yourself on the Admin page, then pick it in the AI menu on the MCPs tab.

Save the address and its models show up to pick from. Empty address removes it. Examples: localhost:11434 (Ollama), localhost:8080 (llama.cpp), localhost:1234 (LM Studio) or an https://…/v1 endpoint; /v1 is added when there's no path. The model needs to handle tool calls.
